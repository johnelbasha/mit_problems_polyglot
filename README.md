# MIT Problems Polyglot

This project contains proposed solutions in various programming languages to problem sets provided through MIT Open Courseware modules.

## Structure

Solutions are organised in the following folder and file structure:

 ->Course Reference Number
   |
   |->course_year_and_season
      |
      |->course_year_and_season
         |
         |->problem_set_number
            |
            |-> programming_language

For example, the first entries that will be committed to this project will be organised as follows:

-> 6.0001
   |
   |-> 2016_fall
       |
       |-> problem_set_0
           |
           |-> Python
           |-> Javascript
           |-> Ruby
           |-> C
           |-> Rust
           |-> Typescript
           |-> Go
